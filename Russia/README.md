# BlockAds RU для Shadowrocket

Быстрый доменный блокировщик рекламы для российских и международных сервисов. В модуле остаётся только секция `[Rule]` с правилами `DOMAIN-SUFFIX,...,REJECT`.

В этой пересборке полностью удалены JavaScript, `[Script]`, `[MITM]`, `hostname`, расшифровка HTTPS и обработка содержимого ответов. Сертификат Shadowrocket создавать не нужно. Модуль не меняет маршрутизацию, DNS, VLESS/Xray или настройки VPN.

## Подключение

В Shadowrocket откройте «Конфиг / Config» → «Модули / Modules» → `+` и добавьте одну ссылку:

[Скачать blockAds-RU.module](https://raw.githubusercontent.com/pivazyaa/blockads-ru/main/Russia/blockAds-RU.module)

Если ссылка уже добавлена, обновите существующий модуль. Должна появиться версия `2026.09.15.1`. Старый общий fmz200-модуль и прежние отдельные модули с MITM отключите, чтобы правила не дублировались.

## Что блокируется

Правила собраны из закреплённых AdGuard Base, Mobile и Russian/Cyrillic списков. Повторяющиеся домены и дочерние записи, уже покрытые родительским доменом, удаляются. Условные правила, URL-пути, регулярные выражения, списки маршрутизации, IP-адреса и правила с контекстом приложения не превращаются в глобальный запрет.

Из правил исключены основные общие службы Apple и iCloud, авторизация, покупки, обновления, банковские приложения, Telegram, Widgetable, Yandex/Telemost, YouTube, TikTok, Reddit и X. Это снижает риск поломок: рекламные запросы, которые используют тот же домен, что и основная функция приложения, могут остаться.

Доменный фильтр не видит рекламу, встроенную в JSON, HTML, видео или единый API вместе с обычным контентом. Поэтому он не обещает убрать все спонсорские публикации в YouTube, Reddit, TikTok или рекламу в Telegram. Для сайтов в Safari косметическая фильтрация AdGuard может дополнительно скрывать элементы страницы, но её не следует включать вторым VPN-профилем поверх текущего VPN.

## Надёжность и приватность

Модуль не читает содержимое запросов, cookies, токены и ответы приложений. Он не устанавливает сертификаты, не выполняет код и не использует удалённые списки во время работы. Все правила зафиксированы в опубликованном файле; обновление происходит только при явном обновлении модуля.

Если после обновления какое-либо приложение ведёт себя неправильно, сначала выключите этот модуль и проверьте приложение. Затем сообщите домен, который блокируется, без cookies, токенов и полного URL с параметрами. Не добавляйте обратно MITM-хосты для исправления доменного правила.

## Проверки и сборка

В релизе **2026.09.15.1** — 2 026 уникальных доменных правил, без скриптов и MITM-секций. `validate-release.ps1` проверяет единственную секцию `[Rule]`, отсутствие директив расшифровки, формат правил, дубли, критические исключения и отсутствие старых JavaScript/модулей.

Для повторной проверки в PowerShell:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\publish\validate-release.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\publish\test-source-exceptions.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\build-rules.ps1
```

Источники и их SHA-256 записаны в `sources.lock.json`. Лицензия GPL-3.0 находится в `LICENSE`.
